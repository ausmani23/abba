# Abba

A strength-and-balance routine app, installable on a phone. Three short
sessions a week at the kitchen counter, a two-minute balance top-up for the
days between, and a progress check every eight weeks. The app runs each
session hands-free: a countdown, beeps, and it moves on by itself.

Live at: **https://adanerusmani.com/abba/**

- To install on iPhone: open the URL in Safari → Share → **Add to Home Screen**.
- To install on Android: open in Chrome → **Install** / **Add to Home screen**.
- Works offline after the first load.

Content lives in [`routines.js`](routines.js). The app shell is shared with
its sibling apps and synced from the `routines` repo — see `CLAUDE.md`.
